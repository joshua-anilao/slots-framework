# Art references

Drop reference images here so Claude can look at them directly (PNG, JPG, WebP).

| Folder | Put here |
|---|---|
| `mood/` | Overall look: colors, lighting, style you like |
| `ui/` | Buttons, panels, popups, fonts |
| `symbols/` | Symbol style examples |
| `fx/` | Win effects, coin bursts, particles |
| `layout/` | Screen layouts and sketches (write feature numbers on them, see docs/SCREENS_AND_FEATURES.md section 8) |

Rules:
- Name files so they say what to take from them: `ui_spin-button_glow-style.png`, `mood_warm-gold-casino.jpg`.
- Add one line per image in `notes.md` if it isn't obvious: what to copy (style, layout, color) and what to ignore.
- References from other games are for **style and layout only**; our art must be original.
- Keep each image under ~1 MB / 1920 px wide so the repo stays light.
- Screenshots of other companies' games: keep the repo private.

A game's own references go in `games/<id>/guides/art/references/` with the same folders.
