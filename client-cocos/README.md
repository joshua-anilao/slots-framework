# client-cocos (Phase 4)

The Cocos Creator production client. Plan: `docs/PHASE4_COCOS_PLAN.md`.

- `assets/shared/` is GENERATED by `npm run sync:cocos` from `packages/math-core` and `packages/game-logic`. Never edit it by hand. `npm run check:cocos` (part of `npm run check`) fails when it is stale.
- `assets/framework/` will hold the reusable modules, `assets/game/` the Fishball Fiesta part. The framework never imports from the game.
- Cocos folders `library/`, `temp/`, `local/` and `build/` are not committed.
